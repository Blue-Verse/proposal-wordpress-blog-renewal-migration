제안 포인트

1. 4단계 무손실 마이그레이션 프로세스

① DB 클리닝(리비전, 스팸 댓글, 만료 트랜지언트 정리) → ② 스테이징 마이그레이션(WP-CLI + 정규식 본문 치환 + 미디어 라이브러리 sync) → ③ 정합성 검증(체크섬 + 1,150건 무작위 샘플 검수) → ④ 운영 컷오버(DNS TTL 단축, 무중단 전환). 1순위인 산출물 완성도를 최우선으로 보장합니다.

2. SEO 연속성 100% 보존 — 트래픽 손실 ZERO 목표

리뉴얼 전/후 URL을 1:1로 매핑하여 301 영구 리다이렉트맵을 구성합니다. 메타 태그(Title, Description)와 정규 URL(canonical), 사이트맵을 신규 환경으로 무손실 이관하고, Search Console과 Bing Webmaster Tools에 신규 사이트맵을 등록하여 인덱싱 회귀를 모니터링합니다.

3. AIEO 시대 대응 — JSON-LD Schema 템플릿화

Article, BreadcrumbList, Organization, WebSite 등 핵심 Schema.org 타입을 테마 레벨에서 템플릿화하여, 신규 작성되는 포스트에도 자동으로 구조화 데이터가 주입되도록 설계합니다. Google Rich Results Test와 Schema Markup Validator로 전수 검증합니다.

4. PHP 7.0 → 8.3 트러블슈팅 노하우

PHP 8.x에서 Removed/Deprecated된 함수(each(), create_function(), mysql_* 등)를 정적 분석 도구(PHPCompatibility, Rector)로 자동 스캔합니다. 플러그인 호환성 매트릭스를 작성하여 단계별 검증 후 적용하며, 호환되지 않는 플러그인은 동등 기능 대체안을 함께 제안합니다.

5. 운영 중인 서비스 리뉴얼 경험

운영 중인 핀테크 플랫폼의 UI/UX 전면 리뉴얼을 80+ 엔티티 규모로 수행한 경험을 기반으로, 데이터 연속성 보장과 무중단 전환에 대한 검증된 프로세스를 적용합니다. 자사 PM 2명과의 협업 환경에서 일일/주간 보고 체계를 정착시킵니다.

  • [필수] 본문 내 하드코딩된 구형 도메인/절대경로 이미지 정규식 일괄 치환
